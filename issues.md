# Lab 5: Static Code Analysis — Issues and Remediation Report

## Identified Issues and Remediation Summary

The following table documents the static code analysis and security findings identified in `premium_calculator.py` using **Bandit**, **Pylint**, and **Flake8**, prioritized by severity (High and Medium severity first).

| Issue | Type | Line(s) | Description | Fix Approach |
|-------|------|---------|-------------|--------------|
| **B202: tarfile_unsafe_members** | Security (High) | 64 | `tarfile.extractall()` is called on user-supplied archives without member validation. An attacker can supply a malicious archive containing path traversal sequences (e.g., `../../etc/cron.d/`) to overwrite arbitrary system files. | Validated archive member destinations ensuring they remain strictly within the target directory, and passed `filter="data"` (Python 3.12 PEP 706) to enforce automated archive data sanitization. |
| **B314 / B405: xml_bad_elementtree** | Security (Medium / Low) | 7, 48 | Untrusted XML is parsed using standard library `xml.etree.ElementTree.fromstring()`. This standard parser is vulnerable to XML External Entity (XXE) injection and quadratic blowup / entity expansion (Billion Laughs) denial-of-service attacks. | Replaced standard `xml.etree.ElementTree` with `defusedxml.ElementTree`, which explicitly forbids entity expansions and external DTD definitions, preventing XXE and DoS attacks. |
| **B323: unverified_context** | Security (Medium) | 58 | The function `fetchRates()` explicitly disables TLS certificate verification using the internal `ssl._create_unverified_context()`. This exposes network communications to man-in-the-middle (MitM) eavesdropping and certificate forgery. | Replaced `_create_unverified_context()` with `ssl.create_default_context()`, enforcing strict certificate authority (CA) verification and hostname validation. |
| **B310: urllib_urlopen** | Security (Medium) | 59 | Calling `urllib.request.urlopen()` with unvalidated URL strings permits arbitrary or unexpected schemes (such as `file://`, `ftp://`, or local resource protocols), leading to Server-Side Request Forgery (SSRF) and local file inclusion. | Implemented strict URL scheme validation (`https` only) and migrated network requests to `http.client.HTTPSConnection` using the verified SSL context. |
| **B104: hardcoded_bind_all_interfaces** | Security (Medium) | 12 | The server host constant is bound to `0.0.0.0`, exposing service endpoints on all public and private network interfaces inadvertently. | Changed the bind address to loopback `127.0.0.1`, restricting exposure to the local host. |
| **B108: hardcoded_tmp_directory & symlink risk** | Security (Medium) | 14, 39–44 | Log file path hardcoded to `/tmp/premium_quotes.log`. On multi-user systems, world-writable `/tmp` allows pre-creation symlink attacks and race conditions (insecure temporary file handling) if opened naively. | Utilized `tempfile.gettempdir()` and hardened `save_quote()` with low-level `os.open()` using `O_NOFOLLOW`, restrictive permissions (`0o600`), and owner/regular-file verification (`fstat.st_uid == os.getuid()`) to fully prevent symlink hijacking. |
| **B105: hardcoded_password_string & fallback token** | Security (Low) | 13, 103 | The underwriter authorization secret token was hardcoded in source code (`UNDERWRITER_TOKEN = "uw-7f3a9c2e1b"`), with a fallback present in demonstration execution. | Removed all hardcoded tokens and fallback defaults. Secret retrieval is strictly dynamic via `os.environ.get("UNDERWRITER_TOKEN", "")`, failing safely when absent, and verified using constant-time `secrets.compare_digest()`. |
| **B311: pseudo_random** | Security (Low) | 37 | Policy identifiers are generated using standard pseudo-random number generator `random.randint()`. Standard PRNGs are deterministic and predictable, allowing attackers to guess generated policy numbers. | Replaced `random.randint()` with cryptographically secure random generation via `secrets.SystemRandom().randint()`. |
| **B112: try_except_continue** | Security / Quality (Low) | 53–54 | Silent suppression of errors inside an XML iteration loop using a bare `try ... except: continue` construct. Masks malformed data and operational anomalies. | Replaced bare except with explicit caught exceptions (`(ValueError, TypeError)`) and added contextual warning logging (`logger.warning`) to maintain auditability. |
| **W0102: dangerous-default-value** | Code Quality / Bug | 17 | `discounts=[]` uses a mutable list as the default parameter. Modifying `discounts` within `calculatePremium` leaks discount amounts across independent function calls. | Changed default parameter to `discounts=None`, instantiated a fresh list copy on each invocation, and removed the state-mutating append operation. |
| **Logic Bug: Birthday Age Calculation** | Functional Bug | 30–33 | `today.year - born.year` incorrectly computes age solely from calendar years, counting applicants as older before their actual birthday has occurred in the current year. | Refactored calculation to compare `(today.month, today.day) < (born.month, born.day)` and subtract 1 if the birthday has not yet occurred. |
| **Logic Bug: Negative Premium** | Functional Bug | 25–26 | Stacked discount deductions without a floor check allow policy premiums to result in negative values. | Added boundary enforcement clamping final premiums to a minimum of `0.0`. |
| **Logic Bug: Leap-Year Rollover** | Functional Bug | 79–81 | `date.replace(year=date.year + years)` crashes with a `ValueError` when renewing a policy initiated on leap day (`February 29`). | Implemented exception handling for February 29th renewals, correctly rolling non-leap year expiration dates to `February 28`. |
| **R0913 / R0917: excessive-arguments** | Code Quality | 17 | Function `calculatePremium` accepted 6 positional parameters, exceeding Pylint's default limits (5 arguments / 5 positional). | Refactored signature with flexible `*extra_args`, keyword-only defaults, and helper extraction functions while maintaining backward compatibility. |
| **W1514 / R1732 / C0209: file-io-quality** | Code Quality | 42–44, 63–65 | File operations opened without `with` context managers, omitted explicit UTF-8 character encoding declarations, and used legacy `%` string interpolation. | Refactored file operations to use `with open(..., encoding="utf-8")` context managers and modern Python f-strings. |
| **C0103 / C0114 / C0116: naming-docstrings** | Code Quality | 1, 17, 30, 36... | Missing module and function docstrings; functions declared using non-PEP 8 camelCase identifiers (`calculatePremium`, `ageFromDob`, etc.). | Added comprehensive docstrings and renamed functions to standard snake_case (`calculate_premium`, `age_from_dob`), preserving legacy names via module `__getattr__`. |
